# Exercise 03 — Budget Tracker

Vanilla JavaScript exercise built with Vite.

## Requirements covered

- Expense name input with `name="expense-name"`.
- Expense amount input with `name="expense-amount"`.
- Button to add expenses.
- Dynamic expense list rendered with JavaScript.
- Running total displayed in `#total`.
- Validation for empty names and non-positive / invalid amounts.
- No frameworks.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
